bug_report What is Debugging?

Debugging is the process of identifying, analyzing, and fixing errors (bugs) in a program so that it works correctly and efficiently. Unresolved errors may cause program crashes, incorrect output, or unexpected behavior.

Syntax Errors

Violations of Python rules (e.g., missing colons, incorrect indentation). The code won't run at all.

Runtime Errors

Errors that occur while the program is running (e.g., dividing by zero, file not found).

Logical Errors

The program runs successfully but produces the wrong output due to flawed logic.

Traceback Analysis

1

Read the last line of the error message to identify the file name, line number, and cause.

ValueError: invalid literal for int()

# Cause: User entered text instead of a number
try:
  quantity = int(input("Enter quantity: "))
except ValueError:
  print("Quantity must be a number.")

Print Debugging

2

Insert print() statements to check variable values and flow control.

print("Subtotal:", subtotal)

# Problem Found: Discount applied incorrectly

  discount = subtotal * 0.10

Input Validation

3

Prevent invalid inputs from breaking the program by checking types and ranges.

if quantity <= 0:
  raise ValueError

# Benefit: Prevents negative or zero quantities.

Step-by-Step (Dry Run)

4

Manually trace program logic using sample data on paper to find mismatches.

# Input: Coffee = 2
# Expected: 450 * 2 = 900
# Actual: Incorrect -> Logic error found
# Fix: Corrected multiplication logic.

Python Debugger (pdb)

5

Pause execution and inspect variables using the built-in debugger.

import pdb; pdb.set_trace()

# Commands:
# n -> next line
# p subtotal -> print variable

Modular Testing

6

Test each function separately with sample data to isolate errors.

# Benefit: Easier to locate specific errors.
