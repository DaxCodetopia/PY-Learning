Written Assignment: KCSMS

Kim's Convenience Store Management System
2000 Words | 50% Total Grade

Assessment Brief

The Scenario

Mr. Kim’s Convenience Store is a small family-run shop currently struggling with manual record books and paper-based registers. This legacy system causes:

  • Incorrect billing calculations
  • Loss of item records
  • Poor stock tracking
  • Delays in sales summaries
  • Misplaced records
  • Frequent shortages/overstocking

The Goal: Design and implement a menu-driven Python application to automate inventory, billing, and reporting. The system must reduce human errors and improve operations for items like Ramen Milk Chips etc.

Functional Requirements

1. Item Display & Inventory

Display all items with: ID, Name, Category (Grocery/Snacks/etc.), Price, Quantity, Stock Status.

Management Actions:

  • Add, Update, Delete items
  • Mark as "Out of Stock"
  • Search by ID or Name
  • Sort by Price, Quantity, or Category

2. Billing & Checkout

Calculate Total = Price × Quantity.

  • Discount: Apply 5% if total exceeds set amount (bulk/regulars).
  • Warnings: Alert if Quantity < 10 units. Prevent selling Out of Stock items.
  • Output: Item-wise breakdown, Subtotal, Discount, Final Payable.

3. Reporting & Safety

  • Generate text report: Total Sales, Revenue, Items Sold, Remaining Inventory.
  • Highlight items needing restock or frequently sold items.
  • Safe Exit: Save all records to prevent data loss.

Non-Functional Requirements

1. Interface & Usability

  • Menu-driven interface
  • Clear output with minimal technical jargon
  • Input Validation: Reject invalid IDs, negative values, and wrong categories.
  • Robust Error Handling: No crashes on incorrect input.

2. Code Quality & Structure

  • Modular Design: Separate functions for Display, Billing, Searching, etc.
  • PEP8 Standards: Proper indentation, meaningful names, docstrings/comments.
  • Scalability: Structure code to allow future features (e.g., Barcode scanning).
Note on Data: Plan how to store data (Dictionaries, Lists, Tuples, or Objects).

Assessment Breakdown

Complete the following tasks and submit as a single report.

Question 1: Program Development 60 Marks

Develop a modularized Python program (KCSMS) meeting all system requirements.

1.1 Technical Document Annex 10 Marks

Length: 1-2 Pages (LO3)

  • Problem Summary: 1 paragraph.
  • IPO Analysis: Table showing Input, Process, and Output.
  • Data Representation Plan: Explain how items/inventory are stored.
  • Function Planning: Table listing functions and purpose (Modularization Map).
  • Algorithmic Logic: Explanation of decision structures/algorithms used.

1.2 Python Program Source File 40 Marks

The actual .py implementation.

1.3 Evidence of Program Run 10 Marks

Screenshots or console logs showing developed functions working.

Question 2: Testing, Debugging & Documentation 40 Marks

Verify all features work correctly and document the process.

  • Test Plan: Input data, Expected output vs Actual output.
  • Debugging: Record errors encountered and how they were resolved.
  • Documentation Report:
    • System Purpose & Features
    • Functions Summary
    • Testing Results
    • Limitations
    • Reflection on the development process
