compare Difference: Functions With Return vs. Without Return
Feature Function with NO Return Function WITH Return
Purpose Performs a task Performs a task and gives back a result
Uses `return` keyword ❌ No ✅ Yes
Output Shows result using `print()` Sends value back to where it was called
Can be stored in variable ❌ No ✅ Yes
Can be used in calculations ❌ No ✅ Yes
Can be reused in other functions ❌ Limited ✅ Very useful
Best for Displaying, messages, reports Calculations, decisions, processing
Example use `print bill`, `show menu`, `display name` `calculate total`, `find max`, `compute salary`
Example: No Return
# Output is printed, but we cannot store the result.

def show_total(a, b):
  print(a + b)

# Calling it
show_total(10, 20)
Example: With Return
# Result can be: printed/stored/used in another calculation

def total(a, b):
  return a + b

# Calling it
result = total(10, 20)
print(result)
