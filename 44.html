Python Stacks: The Clothing Shop

Understanding LIFO, Stack Operations, and Practical Simulation

What is a Stack?

A Stack is a linear data structure that holds a linear, ordered sequence of elements. It is an Abstract Data Type (ADT).

A Stack works on LIFO process (Last In First Out): element that was inserted last will be removed first.

To implement Stack, it is required to maintain a pointer to the top of the Stack, which is the last element to be inserted, because we can access elements only on the top of the Stack.

A Stack can be a fixed specific size, or it can be dynamic (size can be changed dynamically). It can be represented by means of Pointers, Arrays, Structures, and Linked Lists.

Applications of Stack

  • Expression Evaluation: Stacks can be used for evaluating expressions consisting of operands and operators.
  • Backtracking: Stacks can be used for Backtracking, i.e., to check parenthesis matching in an expression.
  • Conversion: It can also be used to convert one form of expression to another form (e.g., Infix to Postfix).
  • Memory Management: It can be used for systematic Memory Management.

Advantages & Disadvantages

Advantages

  • Helps manage data in the ‘Last In First Out’ method.
  • Efficient when variables are not used outside of a function.
  • Allows you to control memory allocation and deallocation.
  • Helps to automatically clean up objects.

Disadvantages

  • Difficult to create many objects; increases risk of Stack Overflow.
  • Has very limited memory compared to Heap.
  • Random access is not possible.

Representation of Stack using Python List

In Python, list is used to implement a stack dynamically. The append() method acts as Push, and pop() acts as Pop.

# Initialize an empty stack
stock = []

# PUSH: Add item to the end of the list (Top)
stock.append("T-Shirt")

# POP: Remove item from the end of the list (Top)
sold_item = stock.pop()

# PEEK: Check the last item without removing it
top_item = stock[-1]

Task: Clothing Shop Simulator

Scenario: Write a small python program that simulates a clothing shop using a stack. This program allows you to add clothing items to the stock, sell items (which removes them from the stock), and display the current stock.

[Demonstrates how a stack can be used to manage inventory in a shop.]

Python Code Solution

# Clothing Shop Stack Program

# Stack to store clothing items
stock = []

# Function to push (add) item to stack
def add_item():
    print("\n--- Add Clothing Item ---")
    
    item_type = input("Enter clothing type: ")
    size = input("Enter size: ")
    price = float(input("Enter price: "))

    # Create clothing item as a dictionary
    item = {
        "Type": item_type,
        "Size": size,
        "Price": price
    }

    # PUSH operation
    stock.append(item)

    print("Item added to stock successfully!")
    print("Push Operation Done!")

# Function to pop (sell) item from stack
def sell_item():
    print("\n--- Sell Clothing Item ---")

    if len(stock) == 0:
        print("Stock is empty!")
    else:
        # POP operation
        sold_item = stock.pop()

        print("Item Sold Successfully!")
        print("Pop Operation Done!")
        print("Sold Item Details:")
        print("Type :", sold_item["Type"])
        print("Size :", sold_item["Size"])
        print("Price:", sold_item["Price"])

# Function to display stock
def display_stock():
    print("\n--- Current Stock ---")

    if len(stock) == 0:
        print("No items in stock!")
    else:
        print("Items from Top to Bottom:\n")

        # Display from top of stack to bottom
        for i in range(len(stock)-1, -1, -1):
            item = stock[i]

            print("Type :", item["Type"])
            print("Size :", item["Size"])
            print("Price:", item["Price"])
            print("-------------------")

# Main program loop
while True:
    print("\n====== Clothing Shop Menu ======")
    print("1. Add Item to Stock (Push)")
    print("2. Sell Item (Pop)")
    print("3. Display Stock")
    print("4. Exit")

    choice = input("Enter your choice: ")

    if choice == "1":
        add_item()

    elif choice == "2":
        sell_item()

    elif choice == "3":
        display_stock()

    elif choice == "4":
        print("Exiting Program...")
        break

    else:
        print("Invalid choice! Please try again.")

Detailed Explanation

1. Clothing Item Structure

Each clothing item stores specific details in a Dictionary:

  • Clothing Type
  • Size
  • Price
item = {
    "Type": "T-Shirt",
    "Size": "M",
    "Price": 2500
}

2. Stack for Stock Management

The program uses a stack to manage stock:

stock = []

A stack follows the rule: LIFO (Last In First Out). This means the last item added is the first item sold.

3. Push Operation (Adding Item)

When new stock arrives, the program uses append():

stock.append(item)

This is called a Push Operation. The item is added to the top of the stack.

4. Pop Operation (Selling Item)

When an item is sold, the program uses pop():

sold_item = stock.pop()

This is called a Pop Operation. The most recently added item is removed from the stack.

5. Displaying Current Stock

The program shows items from Top → Bottom using a reversed loop:

for i in range(len(stock)-1, -1, -1):
