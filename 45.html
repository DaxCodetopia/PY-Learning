Python Queues: The Bank Service

Understanding FIFO, Queue Operations, and Practical Simulation

What is a Queue?

A Queue is a linear data structure that holds a linear, ordered sequence of elements. It is an Abstract Data Type (ADT).

A Queue works on FIFO process (First In First Out): element that was inserted first will be removed first.

To implement Queue, it is required to maintain two pointers: FRONT (points to first element) and REAR (points to last element). Elements are added at Rear and removed from Front.

A Queue can be represented by means of Arrays, Linked Lists, or Pointers. Python's list or queue module are common implementations.

Applications of the Queue

  • CPU Scheduling: Operating systems use queues to manage processes. Tasks waiting for CPU time are lined up to ensure fair execution.
  • Disk Scheduling: Requests to read from or write to a hard disk are queued to optimize data access.
  • Asynchronous Data Transfer: Used for synchronization when data is transferred between processes (e.g., IO Buffers, pipes, file IO).
  • Interrupt Handling: Real-time systems handle interrupts as they arrive, storing them in a queue to be processed sequentially.
  • Call Center Systems: Phone systems place callers in a queue to be served "First Come, First Served".

Advantages & Disadvantages

Advantages

  • FIFO Order: Maintains data order, ensuring fairness in scheduling and serving.
  • Efficient Operations: Enqueue and Dequeue are generally O(1) time complexity.
  • Memory Usage: Dynamic queues don't waste memory like fixed arrays.
  • Data Synchronization: Ideal for handling asynchronous data transfer.

Disadvantages

  • Restricted Access: You cannot access random elements in the middle.
  • Searching: Searching for a specific element is slow (O(n)).
  • Fixed Size Issues: Array-based queues have a limit unless circular.

Representation of Queue using Python List

In Python, list is commonly used. The append() method acts as Enqueue (adds to Rear), and pop(0) acts as Dequeue (removes from Front).

# Initialize an empty queue
bank_queue = []

# ENQUEUE: Add item to the end of the list (Rear)
bank_queue.append("Customer A")

# DEQUEUE: Remove item from the start of the list (Front)
served_customer = bank_queue.pop(0)

Task: Bank Queue Simulator

Scenario: Write a small python program that simulates a bank queue. This program allows you to add customers to the queue (Enqueue), serve them (Dequeue), and display the current queue status.

Python Code Solution

# Bank Queue Simulation Program

# Queue to store customers
bank_queue = []

# Function to enqueue (add) customer
def add_customer():
    print("\n--- Add Customer to Queue ---")

    name = input("Enter customer name: ")
    account_no = input("Enter account number: ")
    service = input("Enter service needed: ")

    # Create customer record
    customer = {
        "Name": name,
        "Account": account_no,
        "Service": service
    }

    # ENQUEUE operation
    bank_queue.append(customer)

    print("Customer added to queue successfully!")
    print("Enqueue Operation Done!")

# Function to dequeue (serve) customer
def serve_customer():
    print("\n--- Serve Customer ---")

    if len(bank_queue) == 0:
        print("Queue is empty!")
    else:
        # DEQUEUE operation
        served_customer = bank_queue.pop(0)

        print("Customer Served Successfully!")
        print("Dequeue Operation Done!")

        print("\nServed Customer Details:")
        print("Name    :", served_customer["Name"])
        print("Account :", served_customer["Account"])
        print("Service :", served_customer["Service"])

# Function to display queue
def display_queue():
    print("\n--- Current Bank Queue ---")

    if len(bank_queue) == 0:
        print("No customers in queue!")
    else:
        print("Customers from Front to Rear:\n")

        for customer in bank_queue:
            print("Name    :", customer["Name"])
            print("Account :", customer["Account"])
            print("Service :", customer["Service"])
            print("----------------------")

# Main program loop
while True:
    print("\n====== Bank Queue Menu ======")
    print("1. Add Customer (Enqueue)")
    print("2. Serve Customer (Dequeue)")
    print("3. Display Queue")
    print("4. Exit")

    choice = input("Enter your choice: ")

    if choice == "1":
        add_customer()

    elif choice == "2":
        serve_customer()

    elif choice == "3":
        display_queue()

    elif choice == "4":
        print("Exiting Program...")
        break

    else:
        print("Invalid choice! Please try again.")

Detailed Explanation

1. Customer Structure

Each customer is stored as a dictionary:

  • Customer Name
  • Account Number
  • Service Needed
customer = {
    "Name": "Kamal",

2. Queue for Bank Customers

The program uses a stack to manage customers:

bank_queue = []

A queue follows the rule: FIFO (First In First Out). This means the first customer who enters the queue is served first.

3. Enqueue Operation (Adding Customer)

When a customer arrives:

bank_queue.append(customer)

This is called an Enqueue Operation. The customer is added to the rear of the queue.

4. Dequeue Operation (Serving Customer)

When a customer is served:

served_customer = bank_queue.pop(0)

This is called a Dequeue Operation. The first customer in the queue is removed.

5. Displaying Current Queue

The program displays customers from Front → Rear:

for customer in bank_queue:
