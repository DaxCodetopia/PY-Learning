category
Test Design Techniques
filter_1 Equivalence Partitioning
Dividing input data into valid and invalid partitions to test representative values.
filter_2 Boundary Value (BVA)
Focusing on the edges between partitions where bugs often reside.
filter_3 Decision Table
Testing combinations of inputs to determine the correct system output.
filter_4 State Transition
Evaluating how the system behaves when moving from one state to another.

The "Box" Approaches
check_circle
Black Box (Functional): Testing based on requirements and functionality without knowing the internal code structure.
check_circle
White Box (Structural): Testing with internal knowledge of the code to verify paths, branches, and statements.
check_circle
Gray Box: A hybrid approach using partial knowledge of the internal logic for testing.
