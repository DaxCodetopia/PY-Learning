Why People Use Machines?
Machines help us automate repetitive tasks, perform complex calculations, increase efficiency, and achieve precision that humans cannot consistently maintain.
input
Input → Process → Output
This is the fundamental model of how machines work. They take input, process it according to instructions, and produce output.
How to Make Milk Tea?
Input: Tea leaves, milk, sugar, water
Process: Brew tea, add milk and sugar, stir
Output: Delicious milk tea!
ATM
Input: Card, PIN, amount
Process: Verify account, check balance
Output: Cash, receipt
Coffee Machine
Input: Coffee beans, water, selection
Process: Grind beans, heat water, brew
Output: Fresh coffee
Vending Machine
Input: Money, selection
Process: Validate payment, locate item
Output: Selected product

What is Programming?
Programming is the way to give instructions to a machine. The sequence of instructions is called a Program.
Each program has:
  • Start - Beginning of execution
  • Some Work - The actual processing
  • End - Termination point
Programs are given/execute through the machine's understood language. Sometimes this leads to:
Spaghetti Code
Unstructured code that's difficult to follow and maintain, with tangled control flow.
Vibe Code
Code that works despite not following conventional patterns or best practices.
