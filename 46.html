The Problem: Finding the Right Order

Searching is the process of finding a specific element in a collection of data. In programming, efficiency is key.

In our Boba Tea Shop, we have a list of orders. Each order has a unique ID. We need to find the correct drink ticket quickly to serve the customer.

We will explore two fundamental algorithms:

  1. Linear Search: Checking every item one by one.
  2. Binary Search: Dividing the sorted list in half repeatedly.

1. Linear Search

Analogous to looking through a messy pile of order tickets. You pick the top one, check it, and if it's not right, you move to the next.

Advantages

  • Works on unsorted data.
  • Simple to implement.
  • Efficient for very small lists.

Disadvantages

  • Slow for large lists.
  • Time Complexity: O(n) (Grows linearly with data).

Python Implementation

def linear_search(orders, target_id):
    # Iterate through the list of dictionaries
    for order in orders:
        if order["id"] == target_id:
            return order  # Found!
    return None  # Not found

2. Binary Search (Introduction)

Analogous to a numbered menu. You open it in the middle. If your target number is higher, you discard the left half. If lower, discard the right half.

Requirement: The list MUST be sorted for Binary Search to work.

Advantages

  • Extremely fast.
  • Time Complexity: O(log n).
  • Efficient for massive datasets.

Disadvantages

  • Data must be sorted first.
  • More complex logic to implement.

Python Implementation

def binary_search(orders, target_id):
    low = 0
    high = len(orders) - 1

    while low <= high:
        mid = (low + high) // 2
        if orders[mid]["id"] == target_id:
            return orders[mid]
        elif orders[mid]["id"] < target_id:
            low = mid + 1  # Look right
        else:
            high = mid - 1  # Look left
    return None
